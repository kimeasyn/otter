# 실제 사용자 관점 UI 리뷰 — 2026-09-12

## 방법과 범위

별도 리뷰 에이전트에게 이전 대화·소스·요구사항·TODO를 전달하지 않고 실제 프리뷰 화면만
탐색하게 했다. 데스크톱 1440×1000, 모바일 390×844에서 사무실·업무·직원·문서·보고 및
대화 동선을 확인했다. 대상은 당시 등록된 `landing-page` 프로젝트다.

실제 사용자 데이터이므로 메시지 전송·모델 실행·승인·거절·저장·삭제·중단·푸시·배포는
하지 않았다. 따라서 완료된 결과물 검토와 신규 생성·실행의 실사용 평가는 이번 범위 밖이다.
파일 변경 승인도 리뷰 당시 실제 대기 목록에서 발견하지 못했다. 해당 화면은 별도 격리 검사로 보완했다.

추가로 파일 변경 승인에서는 코드 전체를 처음부터 펼치지 않고 파일 목록·개수를 먼저 보이게 했다.
전체 변경 내용은 파일을 펼쳐 확인할 수 있으며 긴 코드에는 내부 스크롤을 적용했다. 내용 확인만으로
승인하지 않고, 실행 범위 경고·승인 버튼 및 서버 검증은 그대로 유지한다.

## 남긴 TODO와 완료 기준

아래 항목은 최초 리뷰의 완료 기준이다. 이어진 구현으로 기본 오류 안내와 승인 목적 구분을 반영했으며,
모델 목록 조회는 후속 구현으로 완료했다. 남은 범위는 직원 설정 직접 열기·더 다양한 오류 구조·직원이 제공하는 쉬운 목적 설명이다.

1. **오류 복구 안내 — 높음.** 제공자 오류를 구조화해 한국어 원인·사용자 조치·관련 직원 설정/업무/보고
   동선을 표시한다. 원문은 상세에 보존한다. 현재 직원 설정과 과거 오류를 구별하고 지원 모델을 추측해서
   추천하거나 자동 변경하지 않는다. 미확정 실행을 자동 재시도하지 않는 기존 경계도 유지한다.
   완료 기준: 모델 접근 오류·인증·연결 오류 각각에 실제 확인 가능한 원인과 명시적 복구 동선이 있으며,
   알 수 없는 오류는 확인 불가로 남고 원문을 열 수 있다.
2. **승인 목적 설명 — 높음.** 제공자가 준 요청 이유·연결 업무·검사 대상을 앞에 보여주고 명령과 접근
   범위는 상세히 읽을 수 있게 한다. 설명이 없으면 없다고 알린다. 명령을 근거 없이 ‘안전한 검사’로
   분류하거나 부수 효과가 없다고 단정하지 않는다. 완료 기준: 이유 있음/없음, 파일 변경, 추가 권한,
   외부 전송 가능 명령을 각각 검증하며 설명과 실제 승인 대상이 일치한다.
3. **모바일 사무실 재배치 — 중간.** 대화 접근은 이번에 개선했다. 팀 선택과 사무실 장식을 어떻게
   함께 보여줄지는 직원 수가 많은 사례와 좁은 화면에서 따로 검토한다. 꾸미기 기능과 결합하지 않는다.
   완료 기준: 여러 직원/여러 대기 요청에서도 대화와 사무실 간 전환, 담당자 식별, 요청 읽기가 가능하다.

## 후속 구현 — 오류 설명과 승인 목적 구분

- 업무·대화·실패 보고에 같은 오류 안내 컴포넌트를 적용했다. 알려진 구조의 모델 미지원 응답,
  401/403·인증 오류, 명시적 연결 오류 코드를 한국어로 안내한다. JSON 전체 또는 첫 줄의 오류 응답만
  해석하며 알 수 없는 구조·일반 안내문은 원문을 유지한다. 저장된 오류나 현재 설정을 수정하지 않는다.
- 긴 JSON은 `오류 원문 보기`에 보존하고 그 뒤에 붙은 실행/재시도 주의사항은 접지 않는다.
  과거 오류와 현재 설정이 다를 수 있음을 표시한다. 설정 확인은 화면 이동일 뿐 저장·실행이 아니다.
- 모델 오류는 직원 화면의 프로젝트 설정으로 안내하고, 인증·연결 오류는 실행 환경 화면으로 연결한다.
  업무 카드에서 해당 업무의 보고로 바로 이동할 수도 있다. 직원 설정 모달 직접 열기와 사용 가능한
  모델 목록 조회는 아직 구현하지 않았다. 임의의 모델 자동 추천/교체는 하지 않는다.
- OpenAI Docs로 [공식 인증 문서](https://learn.chatgpt.com/docs/auth)를 확인했다. ChatGPT 구독 인증과
  API 키 인증을 같게 취급하지 않고 실행 환경의 계정·접근 권한을 확인하도록 안내한다. 특정 계정의
  현재 모델 접근 권한이나 과거 오류의 해결 여부를 확인한 것은 아니다.
- 승인 카드는 연결 업무와 직원이 제공한 요청 목적을 먼저 표시한다. 목적이 없으면 누락 사실을
  알리고, 실제 명령과 허용 범위는 유지한다. 명령을 분석해 안전성을 단정하는 요약은 추가하지 않았다.
- UI 33개 테스트·정적 검사·빌드 통과. 격리 업무 브라우저 검사 `/tmp/otter-task-board-ui-B4oNw9`에서
  원문 보존·관련 보고 범위·직원 설정 이동·필터 복귀·업무 미변경·모델 호출 없음·모바일을 확인했다.
- 실제 화면 재리뷰에서도 한국어 설명·과거 기록 안내·설정/보고 진입의 개선을 확인했다.
  `/tmp/otter-error-after-mobile.png`, `/tmp/otter-error-after-mobile-settings.png`는 임시 증거다.
  리뷰어가 지적한 모델 설정값의 확인 방법은 이후 모델 목록 조회 기능으로 보완했다.

### 모델 조회·선택 통합

- 기존 조회 API를 재사용해 설정을 열 때 자동 조회하는 단일 드롭다운으로 합쳤다. 직접 입력란과 별도 조회 버튼은 제거했다.
- 조회된 모델만 선택할 수 있다. 기존 값이 목록에 있으면 유지하고, 목록 밖의 값·미선택·조회 실패·빈 목록에서는 저장을 차단한다.
- 실패·빈 목록일 때만 재시도 버튼을 표시한다. 환경 변경 시 이전 목록과 늦게 도착한 응답은 사용하지 않는다.

- 업로드·색상 편집·꾸미기 상점은 이번 범위에 포함하지 않았다.

### 아바타 의상·캐러셀 보완

- 캐릭터별 정장·카디건·멜빵·야구 재킷·후드로 색상과 의상 실루엣을 구분했다. 기존 SVG 표현과 저장값을 재사용한다.
- 타일형 선택 대신 이전/다음 화살표와 단일 미리보기를 제공한다. 이름·의상·현재 순서를 표시하고 마지막에서 처음으로 순환한다. 키보드 좌우 방향키도 지원한다.
- 외형 선택만으로 설정을 저장하지 않으며 기존 저장 버튼을 사용한다. 저장 중 이동은 막고, 프로젝트/직원별 기존 선택을 유지한다.
